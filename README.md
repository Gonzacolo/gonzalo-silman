# Gonzalo Silman

Personal landing page.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, pnpm.

## Local

```bash
pnpm install
pnpm dev
```

```bash
pnpm lint
pnpm build
```

## Design

References and decisions live in `BRAND.json` and `study/`. Palette is orange accent on cream (user override). Type and chrome from [agustindorego.com](https://www.agustindorego.com/); section rhythm from [tieshunroquerre.com](https://tieshunroquerre.com/); nav, writing list, and footer from [maraoz.com](https://maraoz.com/).
